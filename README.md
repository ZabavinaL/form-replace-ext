# Form Find & Replace

Браузерное расширение (Manifest V3) для массовой подмены значений в полях форм
на текущей странице. Задаёшь правила «найти → заменить» — расширение обновляет
поля и подхватывается даже фреймворками (React, Vue и др.) за счёт событий
`input`/`change`.

Совместимо с Chrome и Яндекс.Браузером (движок Chromium).

## Возможности

- Список правил «найти → заменить» с сохранением между сессиями браузера.
- Два режима сопоставления на каждое правило:
  - **Точное совпадение** — заменяет всё значение поля целиком;
  - **Часть значения** — заменяет все вхождения подстроки внутри значения.
- Признак **«Учитывать регистр»** на каждое правило:
  - установлен — поиск с учётом регистра (`Ivanov` ≠ `ivanov`);
  - снят — регистр игнорируется (`IvanOV` найдёт `ivanov`).
- Отдельное включение/выключение каждого правила.
- Изменяет значения в широком наборе полей:
  - текстовые и числовые `input` (text, number, password, email, url, tel,
    search, date, time и др.);
  - `textarea`;
  - `select`;
  - любые `contenteditable`-блоки (в т.ч. `plaintext-only`);
  - поля внутри `iframe` того же домена.
- Отчёт о количестве изменённых полей.
- Чистый HTML/JS, без сборки и внешних зависимостей.

## Установка

Установка выполняется вручную через режим разработчика браузера (без публикации
в магазине).

### Chrome

1. Открой страницу расширений: `chrome://extensions`.
2. В правом верхнем углу включи переключатель **«Режим разработчика»**.
3. Нажми кнопку **«Загрузить распакованное расширение»**.
4. В диалоге выбора папки укажи каталог проекта `form-replace-ext`
   (в нём лежит `manifest.json`).
5. Расширение появится в списке. Чтобы панель была в панели браузера, закрепи
   иконку расширения через меню головоломки (рядом с адресной строкой).

### Яндекс.Браузер

1. Открой страницу дополнений: `browser://extensions`
   (либо меню ☰ → **Дополнения**).
2. В правом нижнем углу блока «Дополнения из других источников» нажми
   **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное расширение»**.
4. Укажи каталог проекта `form-replace-ext`.
5. Закрепи иконку расширения: клик правой кнопкой по иконке или через меню
   шестерёнки на странице «Дополнения».

> Расширение использует только API, единые для Chromium (`chrome.storage`,
> `chrome.tabs`, content scripts), поэтому поведение в Chrome и Яндекс.Браузере
> одинаковое.

## Использование

1. Открой любую страницу с формами.
2. Кликни по иконке расширения в панели браузера.
3. Нажми **«+ Правило»** и заполни:
   - поле **«Найти»** — что искать;
   - поле **«Заменить на»** — чем заменить;
   - режим сопоставления — «Точное совпадение» или «Часть значения»;
   - чекбокс **«Учитывать регистр»** — включи или выключи по необходимости.
4. При необходимости выключи правило целиком чекбоксом слева или удали кнопкой
   **×**.
5. Нажми **«Применить»** — значения во всех полях форм на вкладке обновятся,
   а под кнопкой появится счётчик изменённых полей.

## Обновление расширения

Расширение загружено распакованным, поэтому **браузер не обновляет его
автоматически** (автообновление работает только для магазина). После изменения
кода версия в `manifest.json` повышается — обнови расширение руками.

### Chrome

1. Открой `chrome://extensions`.
2. Найди карточку Form Find & Replace.
3. Нажми кнопку **⟳ «Обновить»** на карточке. Если её нет (более старая версия
   браузера) — сними и снова включи тумблер расширения, или удали расширение и
   заново нажми «Загрузить распакованное расширение».

### Яндекс.Браузер

1. Открой `browser://extensions` (меню ☰ → **Дополнения**).
2. Найди Form Find & Replace.
3. Кнопка **«Обновить»** (в виде стрелки) на карточке, либо перезапусти браузер —
   большинство изменений вступает в силу после перезапуска. При стабильном
   отсутствии обновления удали расширение и загрузи заново через
   «Режим разработчика».

**Важно:** после обновления открытые ранее вкладки могут продолжать показывать
старое поведение: при первом применении расширение само внедрит скрипт в такие
вкладки, поэтому перезагружать страницу не обязательно. Если применение всё же
не прошло, перезагрузи страницу (`Ctrl+R`) и повтори.

## Ограничения

- Страницы браузера (`chrome://`, `browser://`) и встроенные страницы магазина
  не перехватываются — это ограничение браузера.
- Поля внутри `iframe` **другого** домена недоступны из-за политики безопасности
  браузера (`iframe` того же домена обрабатываются).
- После подмены значение корректно регистрируется событиями `input`/`change`;
  интерфейс страницы (валидация, пересчёт сумм и т.п.) реагирует на изменение.

## Структура проекта

```
form-replace-ext/
├── manifest.json     # Настройки расширения (MV3)
├── popup.html        # Разметка интерфейса
├── popup.css         # Стили интерфейса
├── popup.js          # Логика попапа и хранение правил
├── content.js        # Сканирование полей и подмена значений
├── background.js     # Служебный воркер
├── CHANGELOG.md      # Журнал изменений
└── TECHNICAL.md      # Техническая документация
```

## Разработка

- **Журнал изменений** — `CHANGELOG.md`: что поменялось между версиями.
- **Техническая документация** — `TECHNICAL.md`: архитектура, поток данных
  и обязательный процесс обновления версий и документации.

Правило проекта: после каждого изменения кода или документации записи
добавляются в `CHANGELOG.md`, обновляется `TECHNICAL.md` (при изменении
архитектуры) и `README.md` (при изменении поведения или инструкций), а текущая
версия указывается в `manifest.json`. Подробности — в `TECHNICAL.md`.
