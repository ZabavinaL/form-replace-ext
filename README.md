# Form Find & Replace

Браузерное расширение (Manifest V3) для массовой подмены значений в полях форм
на текущей странице. Задаёшь правила «найти → заменить» — расширение обновляет
поля и подхватывается даже фреймворками (React, Vue и др.) за счёт событий
`input`/`change`.

Совместимо с Chrome и Яндекс.Браузером (движок Chromium).

## Возможности

- Список правил «найти → заменить» с сохранением между сессиями браузера.
- Два этапа работы: **«Найти»** (счёт совпадений с учётом и без учёта регистра,
  список найденных полей) и **«Заменить»** (применение, доступно после
  просмотра результата поиска).
- Гибкая замена по результатам поиска:
  - кнопка **«Заменить»** у каждого найденного пункта — применяет правило только
    к этому полю;
  - чекбоксы у пунктов + чекбокс **«Выбрать все»** (отмечает сразу все записи) +
    кнопка **«Заменить выбранные (N)»** — замена только отмеченных (недоступна,
    пока ничего не отмечено);
  - кнопка **«Заменить все»** — применяет замену ко всем найденным значениям
    без выбора пунктов;
  - клик по значению пункта прокручивает страницу к полю и подсвечивает его;
  - найденный фрагмент выделен **жирным оранжевым** с подчёркиванием.
- После любой замены заменённое значение в попапе показывается **зелёным
  жирным** шрифтом.
- Если значение найдено в нескольких строках списка (`contenteditable` с
  `ol`/`ul`), строки собираются в **один общий блок** с подсказкой «Найдено в
  разных строках одного списка»; найденное в списке выделяется **фиолетовым**.
  Список **разворачивается** кликом по сводке или кнопке **«Выбрать для
  замены»**: отметь нужные строки и нажми **«Заменить»** — заменятся только они;
  без выбора одна кнопка заменяет все строки. Клик по строке списка показывает
  найденное поле на странице. После замены видно, на что заменено (зелёным).
- Кнопка-значок **«Отменить»** (`↺`) открывает меню: **«Отменить последнюю
  замену»** (вернёт последний заменённый пункт) и **«Отменить всё»** (вернёт
  все замены на странице). После отмены значения в списке найденного снова
  показываются как найденные (оранжевым), галочки и кнопки активны.
- При «Найти» найденные слова **на странице** подсвечиваются **оранжевым фоном**
  (в `contenteditable` — сам текст, в `input`/`textarea`/`select` — всё поле).
- Два режима сопоставления на каждое правило:
  - **Точное совпадение** — заменяет всё значение поля целиком;
  - **Часть значения** — заменяет все вхождения подстроки внутри значения.
- Признак **«Учитывать регистр»** на каждое правило:
  - установлен — поиск с учётом регистра (`Ivanov` ≠ `ivanov`);
  - снят — регистр игнорируется (`IvanOV` найдёт `ivanov`);
  - **по умолчанию признак снят** (регистр не учитывается).
- При замене расширение **сохраняет регистр** написанного в поле слова:
  `JOHN` → замена прописными, `John` → замена с заглавной, `john` → как задано
  в правиле.
- Отдельное включение/выключение каждого правила.
- Изменяет значения в широком наборе полей:
  - текстовые и числовые `input` (text, number, password, email, url, tel,
    search, date, time и др.);
  - `textarea`;
  - `select`;
  - любые `contenteditable`-блоки (в т.ч. `plaintext-only`);
  - поля внутри `iframe` того же домена.
- Отчёт о количестве изменённых полей.
- Замена в `contenteditable` (например, внутри нумерованного списка) не ломает
  разметку и стили: обновляется только текст, а списки и форматирование
  сохраняются.
- Чистый HTML/JS, без сборки и внешних зависимостей.

## Установка

Установка выполняется вручную через режим разработчика браузера (без публикации
в магазине).

### Chrome

1. Открой страницу расширений: `chrome://extensions`.
2. В правом верхнем углу включи переключатель **«Режим разработчика»**.
3. Нажми кнопку **«Загрузить распакованное расширение»**.
4. В диалоге выбора папки укажи каталог проекта `form-replace-ext`
   (в нём лежит `manifest.json`).
5. Расширение появится в списке. Чтобы панель была в панели браузера, закрепи
   иконку расширения через меню головоломки (рядом с адресной строкой).

### Яндекс.Браузер

1. Открой страницу дополнений: `browser://extensions`
   (либо меню ☰ → **Дополнения**).
2. В правом нижнем углу блока «Дополнения из других источников» нажми
   **«Режим разработчика»**.
3. Нажми **«Загрузить распакованное расширение»**.
4. Укажи каталог проекта `form-replace-ext`.
5. Закрепи иконку расширения: клик правой кнопкой по иконке или через меню
   шестерёнки на странице «Дополнения».

> Расширение использует только API, единые для Chromium (`chrome.storage`,
> `chrome.tabs`, content scripts), поэтому поведение в Chrome и Яндекс.Браузере
> одинаковое.

### Установка другим человеком (из исходников)

Расширение автономно и не зависит от сервера, аккаунта или личных данных: все
правила хранятся локально у каждого пользователя. Другой человек может установить
его, просто получив код:

1. Скачать код:
   - через git: `git clone https://github.com/ZabavinaL/form-replace-ext`;
   - или через интерфейс GitHub: кнопка **Code → Download ZIP** и распаковать
     архив.
2. Дальше выполнить шаги раздела «Chrome» или «Яндекс.Браузер» выше
   (режим разработчика → «Загрузить распакованное» → выбрать папку проекта).

Требования к доступу к коду:
- если репозиторий приватный — стороннему человеку нужен доступ
  (приглашение в коллабораторы) или готовый `.zip` с файлами;
- упаковать в файл можно также командой `git archive` или zip-необходимый каталог.

Нюансы использования распакованного расширения:
- требует включённого «Режима разработчика»;
- в Chrome у распакованных расширений может появляться предупреждение о
  «developer mode extensions» — это нормально для личной установки;
- без публикации в магазине автообновлений нет: каждый раз код нужно получать
  заново (см. «Обновление расширения»).

## Использование

1. Открой любую страницу с формами.
2. Кликни по иконке расширения в панели браузера.
3. Нажми **«+ Правило»** и заполни:
   - поле **«Найти»** — что искать;
   - поле **«Заменить на»** — чем заменить;
   - режим сопоставления — «Точное совпадение» или «Часть значения»;
   - чекбокс **«Учитывать регистр»** — включи или выключи по необходимости.
4. При необходимости выключи правило целиком чекбоксом слева или удали кнопкой
   **×**.
5. Нажми **«Найти»** — появится сводка по каждому правилу: сколько значений
   найдено с учётом и без учёта регистра, режим (часть значения или полное
   совпадение) и список найденных полей (значение с найденным фрагментом,
   выделенным жирным).
6. Проверь результат поиска. **Клик по значению** покажет поле на странице
   (прокрутка + подсветка оранжевой рамкой). Найденные слова на странице также
   подсвечены оранжевым фоном.
7. Примени замену любым удобным способом:
   - **«Заменить»** у конкретного пункта — только это поле;
   - отметив **чекбоксы** (или нажав **«Выбрать все»**) и нажав общую
     **«Заменить выбранные (N)»** — только отмеченные (включая отмеченные строки
     списков);
   - нажав **«Заменить все»** — сразу все найденные значения, без отметок.
   Под кнопкой появится счётчик изменённых полей.
   После замены новое значение пункта становится зелёным жирным, а оранжевая
   подсветка найденного на странице снимается.
8. Чтобы откатить изменение, нажми кнопку **«Отменить»** (`↺`) вверху попапа и
   выбери **«Отменить последнюю замену»** (вернёт последний пункт и покажет его
   в списке как найденный) или **«Отменить всё»** (вернёт все замены).
9. Если значение найдено в нескольких строках одного списка, в результате поиска
   отобразится общий блок: наведи на него для подсказки, при необходимости нажми
   **«Выбрать для замены»** (или клик по сводке), отметь нужные строки и нажми
   **«Заменить»**. Клик по строке покажет поле на странице. Без выбора кнопка
   заменит все строки списка.
10. Кнопка **«Очистить все»** удаляет все правила и полностью очищает результаты
   поиска и отметки.

## Обновление расширения

Расширение загружено распакованным, поэтому **браузер не обновляет его
автоматически** (автообновление работает только для магазина). После изменения
кода версия в `manifest.json` повышается — обнови расширение руками.

### Chrome

1. Открой `chrome://extensions`.
2. Найди карточку Form Find & Replace.
3. Нажми кнопку **⟳ «Обновить»** на карточке. Если её нет (более старая версия
   браузера) — сними и снова включи тумблер расширения, или удали расширение и
   заново нажми «Загрузить распакованное расширение».

### Яндекс.Браузер

1. Открой `browser://extensions` (меню ☰ → **Дополнения**).
2. Найди Form Find & Replace.
3. Кнопка **«Обновить»** (в виде стрелки) на карточке, либо перезапусти браузер —
   большинство изменений вступает в силу после перезапуска. При стабильном
   отсутствии обновления удали расширение и загрузи заново через
   «Режим разработчика».

**Важно:** после обновления открытые ранее вкладки могут продолжать показывать
старое поведение: при первом применении расширение само внедрит скрипт в такие
вкладки, поэтому перезагружать страницу не обязательно. Если применение всё же
не прошло, перезагрузи страницу (`Ctrl+R`) и повтори.

## Ограничения

- Страницы браузера (`chrome://`, `browser://`) и встроенные страницы магазина
  не перехватываются — это ограничение браузера.
- Поля внутри `iframe` **другого** домена недоступны из-за политики безопасности
  браузера (`iframe` того же домена обрабатываются).
- После подмены значение корректно регистрируется событиями `input`/`change`;
  интерфейс страницы (валидация, пересчёт сумм и т.п.) реагирует на изменение.

## Структура проекта

```
form-replace-ext/
├── manifest.json     # Настройки расширения (MV3)
├── popup.html        # Разметка интерфейса
├── popup.css         # Стили интерфейса
├── popup.js          # Логика попапа и хранение правил
├── content.js        # Сканирование полей и подмена значений
├── background.js     # Служебный воркер
├── icons/            # Иконки расширения (16/32/48/128)
├── CHANGELOG.md      # Журнал изменений
└── TECHNICAL.md      # Техническая документация
```

## Разработка

- **Журнал изменений** — `CHANGELOG.md`: что поменялось между версиями.
- **Техническая документация** — `TECHNICAL.md`: архитектура, поток данных
  и обязательный процесс обновления версий и документации.

Правило проекта: после каждого изменения кода или документации записи
добавляются в `CHANGELOG.md`, обновляется `TECHNICAL.md` (при изменении
архитектуры) и `README.md` (при изменении поведения или инструкций), а текущая
версия указывается в `manifest.json`. Подробности — в `TECHNICAL.md`.
