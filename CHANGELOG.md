# Журнал изменений (CHANGELOG)

Все изменения кода и документации фиксируются здесь. Формат основан на
[Keep a Changelog](https://keepachangelog.com/ru/1.1.0/), версии — по
[Semantic Versioning](https://semver.org/lang/ru/). Детали реализации — в
`TECHNICAL.md`; пользовательские инструкции — в `README.md`.

## Типы записей

- **Added** — новая функциональность.
- **Changed** — изменения существующей функциональности.
- **Deprecated** — объявленная устаревшей функциональность.
- **Removed** — удалённая функциональность.
- **Fixed** — исправления ошибок.
- **Security** — исправления уязвимостей.
- **Docs** — изменения документации.

## [1.2.0] - 2026-10-30

### Added
- Иконки расширения (16/32/48/128 PNG) для страницы расширений, тулбара
  и упаковки. Концепция: лупа поиска с символом «A» и стрелкой замены.
- `manifest.json` — добавлены блоки `icons` и `action.default_icon`.

### Changed
- `manifest.json` — версия повышена до `1.2.0`.

### Docs
- `README.md` и `TECHNICAL.md` — в структуру проекта добавлена папка `icons/`.

## [1.1.1] - 2026-10-30

### Fixed
- Первое применение на странице, открытой до установки/обновления расширения,
  больше не требует перезагрузки: если content script отсутствует, он внедряется
  на лету через `chrome.scripting.executeScript`, после чего правила применяются
  сразу. Ранее в таких случаях показывалось «Перезагрузи страницу и попробуй
  снова (нет доступа)».

### Changed
- `manifest.json` — добавлено право `scripting`, версия повышена до `1.1.1`.

### Docs
- `README.md` и `TECHNICAL.md` — описан механизм внедрения скрипта на лету,
  убрана необходимость перезагрузки страницы после обновления.

## [1.1.0] - 2026-10-30

### Added
- Признак «Учитывать регистр» для каждого правила: при установленном флаге
  поиск учитывает регистр, при снятом — игнорирует его.
- Поддержка любых `contenteditable`-блоков (ранее только `[contenteditable="true"]`).
- Обработка полей внутри `iframe` того же домена.
- Разделы в `README.md`: «Обновление расширения» и инструкция установки
  и обновления для Яндекс.Браузера.

### Changed
- Расширен набор обрабатываемых типов полей форм (`input` текстовых и числовых
  типов, `textarea`, `select`, `contenteditable`, `iframe` того же домена).
- Оптимизация для Яндекс.Браузера: расширение использует только общие
  Chromium API, общие для Chrome и Yandex, и не требует отдельного портирования.
- `manifest.json` — версия повышена до `1.1.0`.

### Docs
- `TECHNICAL.md` — описаны расширенный набор полей, учёт регистра,
  обработка iframe и совместимость с Яндекс.Браузером.

## [1.0.0] - 2026-10-30

### Added
- Расширение Form Find & Replace для браузера (Manifest V3).
- Попап-интерфейс управления правилами «найти → заменить».
- Два режима сопоставления: точное совпадение и часть значения.
- Сохранение правил в `chrome.storage.local` между сессиями.
- Подмена значений в полях input, textarea, select и contenteditable.
- Инициализация событий `input`/`change` после подмены.
- Отчёт о количестве изменённых полей.
- `README.md` — инструкция по установке и использованию.
